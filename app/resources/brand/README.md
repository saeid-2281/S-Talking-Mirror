# S Talking Brand Assets

The S Talking mark combines a controlled waveform with an abstract conversation path. It is original project artwork and is safe to package with the application.

## Files

- `logo-symbol.svg`: standalone symbol for app surfaces.
- `logo-horizontal-dark.svg`: lockup for dark backgrounds.
- `logo-horizontal-light.svg`: lockup for light backgrounds.
- `app-icon.svg`: source for Windows icon and PNG exports.
- `favicon.svg`: compact browser/report icon.
- `wordmark.svg`: wordmark-only asset.
- `monochrome.svg`: single-color symbol for constrained contexts.
- `app-icon.ico`: Windows multi-size icon generated from `app-icon.svg`.
- `app-icon-*.png`: generated previews and build inputs.

## Usage

Keep clear space around the symbol equal to at least one quarter of its width. Minimum recommended size is 16 px for the symbol and 120 px wide for the horizontal lockups. Do not recolor the gradient, distort the symbol, add drop shadows, or place it on low-contrast backgrounds.
