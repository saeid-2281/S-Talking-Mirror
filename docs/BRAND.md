# S Talking Brand Foundation

## Name

**S Talking**

## Descriptor

Professional AI Audio Studio

## Core positioning

A calm, dependable production tool for turning structured educational text into
natural speech at scale.

## Approved visual direction

- Primary mark: existing ornate golden S emblem
- Premium but not visually heavy
- Dark and light variants
- Spacious interface suitable for long work sessions
- Avoid excessive gradients inside the working interface
- Gold is reserved for identity, highlights, and premium surfaces
- Operational states use familiar success, warning, and error colors

## Initial palette

- Brand gold: `#C99A2E`
- Deep charcoal: `#111827`
- Slate surface: `#1F2937`
- Light canvas: `#F8FAFC`
- Primary action: `#2563EB`
- Accent: `#14B8A6`
- Success: `#22C55E`
- Warning: `#F59E0B`
- Error: `#EF4444`
