# S Talking Brand Foundation

S Talking is an AI Audio Studio: precise, calm, modern, trustworthy, and suitable for long production sessions.

The current identity is documented in:

- `docs/BRAND_SYSTEM.md`
- `docs/DESIGN_SYSTEM.md`
- `docs/UI_COMPONENTS.md`

Canonical assets live in `app/resources/brand/`. Use the waveform/conversation symbol and Brand Blue, Voice Teal, and Warm Accent palettes. Warm Accent is reserved for warnings, quota attention, and favorites; it is not the dominant action color.
