# Text Studio Professional v0.24

Text Studio is now available as a persistent dockable workspace in addition to
its existing quick-import dialog.

## Workspace features

- Manual text and multi-document input
- Drag and drop for all supported text document formats
- Smart, paragraph, sentence, line, or whole-source splitting
- Editable filenames and full chunk text
- Merge, split, delete, enable, and disable chunk actions
- Live character and estimated-duration totals
- Persistent unfinished sessions stored in the application data directory
- Direct import through the existing normalized CSV, source review, preflight,
  and queue pipeline

The workspace is available from **Project > Open Text Studio** and
**View > Text Studio**. Closing the dock does not discard the session.
