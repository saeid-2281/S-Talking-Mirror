# Provider Brand Assets

S Talking uses provider names and neutral local icons for identification. No official third-party provider logos are bundled in this repository unless a future approved asset source and license note is added here.

| Provider | Display name | Bundled asset | Source/license basis | Fallback behavior |
| --- | --- | --- | --- | --- |
| `mock` | Mock / Test Provider | None | Local S Talking test provider, no external brand. | Neutral action icon. |
| `piper` | Piper | None | No approved provider mark bundled. | Neutral local-provider icon plus provider name. |
| `elevenlabs` | ElevenLabs | None | Official mark not bundled to avoid unclear redistribution rights. | Neutral cloud-provider icon plus provider name. |
| `openai` | OpenAI | None | Official mark not bundled to avoid unclear redistribution rights. | Neutral cloud-provider icon plus provider name. |
| `azure` | Microsoft Azure Speech | None | Official mark not bundled to avoid unclear redistribution rights. | Neutral cloud-provider icon plus provider name. |
| `google` | Google Cloud Text-to-Speech | None | Official mark not bundled to avoid unclear redistribution rights. | Neutral cloud-provider icon plus provider name. |
| `aws_polly` | Amazon Polly | None | Official mark not bundled to avoid unclear redistribution rights. | Neutral cloud-provider icon plus provider name. |
| `kokoro` | Kokoro | None | No approved local mark bundled. | Neutral local-provider icon plus provider name. |

The approved S Talking master SVG is stored unchanged at `app/resources/brand/official/S-Logo.svg`. The master hash is documented in `docs/BRANDING.md` and verified by automated tests.
